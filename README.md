Genetic Algorithms — Python
A Python-based academic project exploring the implementation and evaluation of genetic algorithms for optimization problems. The project focuses on the core evolutionary steps of selection, crossover, mutation and fitness evaluation, together with experiments that examine how the algorithm behaves under different conditions.
Overview
The goal of the project was to gain practical experience with evolutionary optimization and to analyze the behaviour of a genetic algorithm through experiments and documented results.
The work includes:
- population-based optimization,
- fitness evaluation,
- selection of individuals,
- crossover operations,
- mutation operations,
- repeated experimental runs and result analysis,
- an optimization experiment involving the Travelling Salesman Problem (TSP).
Core Concepts
Selection
Individuals are selected from the current population based on their fitness so that stronger candidates have a greater chance of contributing to the next generation.
Crossover
Selected individuals are combined to create new candidate solutions and introduce new combinations into the population.
Mutation
Random changes are applied to selected candidates to maintain diversity and help the algorithm explore new areas of the search space.
Fitness Evaluation
Each candidate solution is evaluated using a fitness function. The fitness value provides the basis for comparing solutions and guiding the evolutionary process.
Experiments
The project includes multiple runs of the genetic algorithm and examines the resulting behaviour and output. Particular attention was paid to:
- changes in solution quality across generations,
- the effect of evolutionary operators,
- runtime behaviour,
- the quality and consistency of the produced solutions.
The experimental results and observations are documented alongside the implementation.
